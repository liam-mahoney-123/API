# Cross-Region Post-Trade Equities Normalization Prototype

Runnable Python prototype that ingests post-trade events from multiple regions and publishes one canonical, downstream-friendly contract.

## What this demonstrates

- Region-specific schema/code differences collapsed into one model.
- Validation + data quality checks before publish.
- Canonical mapping of lifecycle, side, venues, account/book, identifiers, currency/FX, timestamps.
- Lineage for every canonical field (`source_path`, raw value, and transforms applied).
- Deterministic handling of duplicates, late arrivals, and sequencing gaps.
- Quarantine for bad/incomplete events and replay after payload fixes.

## Repository layout

```text
normalization/
  canonical.py
```

## Quick start

```bash
python -m pip install -r requirements.txt
python demo.py
```

Demo writes:

- `output/normalized_events.json`
- `output/quarantine_events.json`
- `output/replayed_events.json`
- `output/initial_process_result.json`

## Run tests

```bash
python3 -m pip install -r requirements.txt
python3 -m pytest -q
```

## Why this helps

1. **Less downstream branching logic**: consumers read one contract.
2. **Better reconciliation + auditability**: deterministic transforms and explicit lineage.
3. **Faster onboarding for new regions/venues**: add mapping rules rather than rewriting consumers.
